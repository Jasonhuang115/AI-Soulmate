# 上下文压缩

日期：2026-09-15  
状态：v1 已实现。对照 [memory-system.md](memory-system.md)。

压缩一次调用不写记忆档案、不改 Soul。被裁原文仍在 `turns.sqlite`，人离开后的巩固循环用 `search_turns` 再扫。

## 这次摘要到底在干什么

窗口满了，最旧的轮次会从阿澄眼前消失。摘要只补**被裁掉的那一截**里、人设和近期原文盖不住的东西。

它不负责「记住他是谁」——那是记忆。它负责：**压完她还是同一个人，这段相处里对她有效的增量还在。**

闲聊为主时摘要可以几乎全空。空是正确结果。拿不准不写。禁止为了填表编造议题。

## 三层谁说了算

```
Soul（01-soul.md）     她是谁。宪法。聊天不改。
记忆（MEMORY.md 等）   稳定下来的他、你们、小名的长期住所。
滚动摘要 + 近期原文    这段还有效的相处增量。记忆还没接住时也要能用。
```

Soul 最高。外号不会改她的名字：她叫阿澄；他叫她澄澄，她知道是在叫自己。小名的长期位置在记忆（`relationship.md` → 工作集）。**即使还没进记忆，压缩摘要里也必须留着这条互称**，否则裁掉前缀后她会听不懂。

冲突时：Soul 的自我认知不变；摘要只写「他这样叫我 / 他希望被这样叫」，不写「我改名叫…」。

## 必须保存

只写**现在还有效**的。已过的玩笑、已消退的情绪丢掉。承诺、纠偏、伤心句、小名尽量逐字。

1. **互称**  
   他怎么叫她、她该怎么叫他。这是人设一致性，不是改 Soul。
2. **纠偏与边界**  
   别那样叫我、哪句过分了、不要再提某事。没有它，她会用已经被否决的语气或称呼。
3. **还没散的口气**  
   这段未落地的心情和原因，人话，不要量表。没有它，刚难受完还会贫。已消退的不写。
4. **短线约定**  
   今晚、稍后、你说过会…、他说以后再说。没有它，线出在很早的前缀、尾巴已经聊到别处时会蒸发。
5. **接话还用的短事实**  
   被裁前缀里刚说、档案里未必已有的。这是记忆接住之前的支架，不是第二份用户档案。互称走第 1 条，不写在这里。

## 必须丢弃

- 把陪聊总结成「今日议题 / 当前目标 / 下一步任务」
- 寒暄、嗯嗯、复读、过场式的吃什么和天气
- 已经结束、他也不想再提的闲话
- 表情和动作标记、工具痕迹
- 她自己的长独白（不把她的话当记忆，也不写回 Soul）
- 小说编年、几小时闲聊的剧情复述
- 对 Soul 的改写（「从此她叫澄澄」）
- 已经进记忆、且近期原文里用不到的旧事实（压缩不替记忆做档案）

## 怎么压

一次异步、无工具 LLM。输入：旧滚动摘要 + 即将裁掉的完整轮次。输出：新摘要，**整份替换**，不要往下叠。近期原文留下。失败则短拼接，消息照样裁。

对她只说脉络还在，自然接上。禁止对用户提起压缩或摘要。落到 `data/memory/rolling.md`。注入用内部槽「近期脉络」。

旧摘要里已经关掉的线删掉。矛盾时新的覆盖旧的。

时机：1M 窗口预留 15%，整包 prompt 超过 85% 就在一轮结束后后台压。不挡开口。断线不清空窗口。

## 检查清单

默认每一项「无」。不得为填表发明任务。全文大约两千字以内。

1. 互称  
2. 纠偏与边界  
3. 还没散的口气  
4. 短线约定  
5. 接话还用的短事实  

不要单开「此刻在聊什么」：此刻在还没裁掉的原文里。不要单开金句栏：逐字写在对应项里。
